# Dio-AI
IA, LLMS, Machine Learning, Visão Computacional.
📒 Descrição

Projeto desenvolvido com foco em aprendizado de computação em nuvem utilizando Microsoft Azure. Durante o projeto, explorei conceitos fundamentais de infraestrutura em nuvem, máquinas virtuais, armazenamento, redundância, redes virtuais e gerenciamento de recursos no Azure. O objetivo foi entender na prática como os serviços em nuvem funcionam e como podem ser aplicados em ambientes corporativos.

⸻

🤖 Tecnologias Utilizadas

* Microsoft Azure
* Azure Virtual Machines
* Azure Storage Account
* Azure Blob Storage
* Azure Files
* AzCopy
* GitHub
* ChatGPT para apoio nos estudos e organização dos conteúdos

⸻

🧐 Processo de Criação

O projeto foi desenvolvido através dos cursos e laboratórios práticos da plataforma DIO￼, onde aprendi a criar e configurar recursos no Azure. Durante os estudos, realizei testes com máquinas virtuais, gerenciamento de armazenamento em nuvem, redundância de dados e transferência de arquivos utilizando AzCopy. Também utilizei o GitHub para documentar minha evolução e organizar os aprendizados.

⸻

🚀 Resultados

Como resultado, adquiri uma base sólida em computação em nuvem e serviços Azure, entendendo conceitos importantes como:

* Modelos de serviço em nuvem
* Infraestrutura virtual
* Redes e emparelhamento de redes
* Tipos de armazenamento
* Contas de armazenamento
* Redundância de dados (LRS, GRS e ZRS)
* Upload e gerenciamento de arquivos na nuvem

Além disso, desenvolvi maior familiaridade com ferramentas utilizadas no mercado de infraestrutura e cloud computing.
